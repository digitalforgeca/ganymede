# Ganymede Development Skill

Ganymede is a Discord bot gateway that bridges the Antigravity CLI (`agy`) to Discord, allowing users to interact with AI agents securely via text channels.

## Core Concepts & Lifecycle
- **Gateway vs. SDK**: Ganymede does NOT use the Python Antigravity SDK directly because direct SDK calls bypass rate-limiting, model routing, and persistence. Instead, Ganymede creates a subprocess running the `agy` CLI for each session (using `tmux` in the background).
- **Communication Pipeline**: The input to the agent is injected via a PTY (tmux). The output from the agent is **never** read via stdout. Instead, Ganymede uses a telemetry plugin called **Chalice** which hooks into the agent's lifecycle.
- **Chalice Plugin**: When `agy` finishes generating a response, the Chalice plugin fires a `Stop` hook and writes a telemetry event to a file. Ganymede listens for this event, reads the `transcriptPath` provided by Chalice, extracts the clean output, and streams it to Discord.

## Repository Structure & Customization
- `src/ganymede/`: The core source code for the Ganymede application.
  - `core/agent_manager.py`: Manages the `agy` subprocesses, `tmux` sessions, reads from the Chalice telemetry, and parses artifacts.
  - `core/router.py`: Handles incoming Discord messages, routes them to `AgentManager`, and handles scheduled/background tasks.
  - `platforms/discord/streamer.py`: Manages the rate-limited chunked streaming of text and files back to Discord.
  - `platforms/discord/adapter.py`: Acts as the bridge between Discord.py and the Ganymede core router.
- `plugins/chalice/`: The Chalice telemetry plugin. Installed automatically by `cli.py` when Ganymede starts.

## Gotchas & Pitfalls
- **Naming Scheme Is Sacred**: Internal conversation IDs use underscores (e.g., `ganymede_discord_12345`). Do not rename files, migrate naming schemes, or convert underscores to hyphens. At the CLI boundary, a deterministic `uuid5` is derived for compatibility.
- **Artifacts**: Artifacts generated by the agent are placed in its isolated `brain` directory. `agent_manager.py` syncs these back to the channel's root `brain` directory and adds them to `metadata["artifact_files"]` for `streamer.py` to attach to Discord messages.
- **Discord File Limits**: When attaching files to Discord responses (e.g., artifacts), always ensure they are under the free tier limit (currently 10MB, safely capped at 8MB in streamer logic) to prevent `HTTPException` crashes.
- **Model Restrictions**: All invocations of `agy` must use Gemini models by default because they have large usage limits. Do not hardcode Claude or OpenAI unless the user explicitly requested `/model claude-...`.

## Developing and Customizing
When the user asks you to modify Ganymede:
1. Make your changes in the Python source files under `src/ganymede/`.
2. Do not modify the virtual environment files (`.venv`).
3. You do not need to restart the bot manually; the user will handle deployment or restarting if needed, but you can build the binaries or run test scripts if asked.
4. When editing Discord message handling, remember that message chunking and markdown code fence balancing is done in `streamer.py`.
